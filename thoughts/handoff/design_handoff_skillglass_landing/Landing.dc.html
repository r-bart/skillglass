Cómo funciona

Se pone en marcha en tres pasos. Ninguno escribe nada.

1

Elige las carpetas

Skillglass detecta los runtimes que tienes y te propone las raíces que va a mirar, etiquetadas por escribible, gestionada, de solo lectura o ausente. Tú marcas cuáles entran.

2

Escanea sin escribir

El escaneo lee y no modifica ni un archivo. Al terminar tienes el inventario completo: nombre, descripción, ruta canónica, ámbito, procedencia y validez de cada instalación.

3

Mira, aprende, edita

Abre una skill y lee cómo está escrita. Cuando quieras cambiarla o crear una nueva, cada escritura empieza con un plan que puedes revisar y termina con un snapshot que puedes deshacer.

How it works

It gets going in three steps. None of them write anything.

1

Pick the folders

Skillglass detects the runtimes you have and proposes every root it wants to scan, labelled writable, managed, read-only or missing. You decide which ones are in.

2

Scan without writing

The scan reads and changes nothing. When it finishes you have the full inventory: name, description, canonical path, scope, provenance and validity for every installation.

3

Look, learn, edit

Open a skill and read how it is written. When you want to change it or write a new one, every write starts with a plan you can review and ends with a snapshot you can undo.

Capacidades

Sí, puede hacer todo esto.

Buscar y filtrar

Busca por nombre, descripción, ruta o metadatos. Filtra por runtime, validez, procedencia, origen y estado de actualización. Agrupa por autor o paquete, pero solo cuando esos datos existen de verdad.

Saber cuál gana

Cuando dos skills comparten nombre, Skillglass te dice qué archivo concreto tomará efecto en cada ámbito, y qué instalaciones quedan tapadas.

Validar la estructura

Revisa el SKILL.md y las referencias a recursos locales de forma estática, sin ejecutar nada del contenido importado.

Instalar y actualizar

Instala desde carpeta o ZIP en raíces que tú has aprobado. Cada operación se previsualiza como plan, se escribe de forma atómica y deja un snapshot recuperable.

Editar y crear

Un espacio de trabajo con Vista previa, Código y Cambios sobre la misma instalación observada: lees cómo está hecha, la editas y ves el diff exacto antes de aplicar.

Deshacer de verdad

Un journal persistente recupera operaciones interrumpidas, y el deshacer sigue disponible después de reiniciar la aplicación.

Capabilities

Yes, it can do all of this.

Search and filter

Search by name, description, path or observed metadata. Filter by runtime, validity, provenance, source and update state. Group by author or package, but only when that data actually exists.

Know which one wins

When two skills share a name, Skillglass tells you the exact file that will take effect in each scope, and which installations end up shadowed.

Validate the structure

It checks SKILL.md and local resource references statically, without executing anything from imported content.

Install and update

Install from a folder or a ZIP into roots you approved. Every operation is previewed as a plan, written atomically, and leaves a recoverable snapshot behind.

Edit and create

A workspace with Preview, Code and Changes over the same observed installation: read how a skill is built, edit it, and see the exact diff before anything is applied.

Undo that holds

A persistent journal recovers interrupted operations, and undo still works after you restart the application.

La interfaz

Cada fila lleva su evidencia encima.

No hay una puntuación de salud que lo resuma todo. Validez, origen y actualización son tres cosas distintas y se muestran por separado. Cuando un dato no está disponible, dice «Sin datos» en vez de inventarlo.

The interface

Every row carries its own evidence.

There is no single health score that flattens everything. Validity, source and update state are three different things and they are shown separately. When a value is unavailable it says "Sin datos" instead of inventing one.

Límites de seguridad

¿Te preocupa que toque tus archivos? A nosotros también.

Son límites del producto, no una lista de pendientes. Si algo de esto cambia algún día, será con su contrato de datos y seguridad delante.

  • Nunca activa, desactiva ni desinstala una skill. Eso lo gestionas en tu propio harness.
  • Nunca pide permisos de administrador ni root, ni escalada del sistema operativo.
  • Solo escribe dentro de raíces que tú has aprobado y que son escribibles por tu usuario. Lo gestionado, del sistema o restringido es siempre de solo lectura.
  • Nunca ejecuta el contenido importado. Se trata como no confiable durante la inspección y la instalación.
  • No hay telemetría de uso ni frases del tipo «sin usar desde hace 74 días». Si no se puede observar, no se afirma.
  • Nada de cloud, cuentas, equipos ni sincronización. El índice SQLite y el material de recuperación viven en tu carpeta de datos de usuario y no se suben.

Safety boundaries

Worried it will touch your files? So were we.

These are product boundaries, not a to-do list. If any of them ever change, it will be with their data and security contract in place first.

  • It never activates, deactivates or uninstalls a skill. You manage that in your own harness.
  • It never asks for administrator or root rights, or any operating-system elevation.
  • It writes only inside roots you approved that your user can write to. Managed, system and restricted locations are always read-only.
  • It never executes imported content. It is treated as untrusted during inspection and installation.
  • No usage telemetry and no lines like "unused for 74 days". If it cannot be observed, it is not claimed.
  • No cloud, accounts, teams or sync. The SQLite index and recovery material live in your per-user application-data directory and are never uploaded.

Descarga

Solo desde la página de Releases. En serio, solo desde ahí.

No hay tiendas de aplicaciones, ni espejos, ni portales de descarga, ni actualizador automático. Un binario que venga de cualquier otro sitio no es un binario oficial de Skillglass.

Cada release incluye SHA256SUMS.txt y build-metadata.json. Verifica el checksum antes de ejecutar lo que has descargado.

Los builds todavía no llevan identidad de editor firmada por el sistema. En macOS usan una firma de integridad ad-hoc y no están notarizados, así que el sistema puede avisarte de un desarrollador no verificado.

Preguntas

Y sí, ya sabemos lo que vas a preguntar.

¿Va a tocar mis skills sin avisar?

No. Las lecturas no modifican nada, y cualquier escritura empieza con un plan que ves antes de aceptar. Cada operación soportada deja un snapshot recuperable y una entrada en el journal.

¿El deshacer es una desinstalación?

No. El rollback solo existe para el árbol exacto e intacto que creó una operación registrada por Skillglass. No es una función general de desinstalar.

¿Hay un marketplace de skills?

Todavía no. El MVP no incluye registro remoto ni instalación desde URLs arbitrarias. Se instala desde carpeta o ZIP, en raíces que has aprobado.

¿Genera skills con IA?

No en esta versión. El análisis, el feedback y la reescritura por agente quedan para un contrato de producto posterior. Lo que sí tienes es un editor decente y el diff exacto.

¿Qué se guarda en mi máquina?

Un índice SQLite y el material de recuperación, bajo tu carpeta de datos de usuario. En POSIX, la carpeta va a modo 0700 y la base de datos a 0600. Nada de eso se sube a ningún sitio.

¿Cuánto historial se conserva?

Los últimos 30 snapshots por instalación, o todos los de los últimos 90 días, lo que conserve más historial recuperable. El snapshot al que apunta el inventario actual nunca se elimina.

Questions

And yes, we know what you're going to ask.

Will it touch my skills without asking?

No. Reads change nothing, and any write starts with a plan you see before accepting it. Every supported operation leaves a recoverable snapshot and a journal entry.

Is undo the same as uninstall?

No. Rollback exists only for the exact unchanged tree created by a recorded Skillglass operation. It is not a general uninstall feature.

Is there a skill marketplace?

Not yet. The MVP has no remote registry and no installing from arbitrary URLs. You install from a folder or a ZIP, into roots you approved.

Does it generate skills with AI?

Not in this version. Agent analysis, feedback and rewriting are deferred to a later product contract. What you do get is a decent editor and the exact diff.

What is stored on my machine?

A SQLite index and operation-recovery material, below your per-user application-data directory. On POSIX the directory is forced to 0700 and the database to 0600. None of it is uploaded.

How much history is kept?

The latest 30 snapshots per installation, or every snapshot from the last 90 days, whichever keeps more recoverable history. The snapshot referenced by the current inventory is never pruned.
